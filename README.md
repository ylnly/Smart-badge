# 🌟 Smart Badge · AI 智能吧唧

> 让谷子"活"过来 —— 一枚可以佩戴的二次元 AI 陪伴徽章。
> 它会呼吸、会眨眼，你摇晃它时它会跟着晃，安静时它会自己发呆。

传统吧唧是"印着角色的铁皮"，我们要做的是**"角色本人住在里面"**。

## 📐 核心规格（规划中）

| 项目 | 方案 |
|------|------|
| 屏幕 | 2.06" 圆形 IPS LCD · 480×480 · GC9A01（**与 1.85" QSPI AMOLED 对照实测后定案**） |
| 主控 | ESP32-S3 N16R8（双核 240MHz · 16MB Flash · 8MB 八线 PSRAM） |
| 传感 | BMA456 加速度计（摇晃/倾斜/拿起/放下/走路）+ **环境光传感器**（佩戴/进包检测） |
| 音频 | INMP441 麦克风 + MAX98357A 功放 + Ø15~20mm 超薄扬声器 |
| 识别 | NFC（碰一碰验真 / 校时 / 底座识别） |
| 交互 | 内圈电容触摸环（用主控原生触摸，零额外芯片）+ 背面隐藏复位键 |
| 外径 | Ø63mm（对齐 58mm 吧唧手感）· 厚度 **≤12mm** · **≤45g（目标 40g）** |
| 佩戴 | 蝴蝶扣针背扣，可直接扎在痛包上 |
| 连接 | WiFi 2.4GHz + BLE 5.0（OTA、配网、云端 AI） |

## ✨ 体验设计要点

- **陪伴感，非养成**：不喂食、不升级、没有任务 KPI，角色只是"在你身边活着"
- **柄图是灵魂**：每一帧截图都必须能当壁纸，动画幅度宁小勿崩
- **待机永不整屏位移**：角色靠眼睑、瞳孔、嘴型、发梢的局部差分"活着" —— 硬件带宽的约束，恰好成了更好看的美学法
- **物理互动**：轻摇会晃、猛摇会晕、倾斜会滑、走路会跟着起伏
- **自主行为**：发呆、打哈欠、哼歌、自言自语 —— 它不等你操作
- **去 UI 化**：屏幕上没有进度条、弹窗和电量数字，一切状态都由角色的动作表达
- **离线优先**：断网也有完整体验，联网后解锁 LLM 自由对话

## 🗺️ 开发路线

| 阶段 | 目标 | 周期 |
|------|------|------|
| P1 原型验证 | 跑通"摇晃 → 角色跟着动" | 6~8 周 |
| P2 离线体验 | 多层动画 + 情绪引擎 + 音频 | 6~8 周 |

## 📦 关于角色素材

本项目采用**可热插拔的独立角色资产包**（`.charpkg`）管理内容，
角色表现与硬件、固件完全解耦 —— 换角色不需要改代码。

仓库内**不包含任何角色美术、音频或视频资产**，只保留资产包的格式规范与工具链。
用于演示的角色内容需由使用者自行准备，并确保你拥有相应的权利。
