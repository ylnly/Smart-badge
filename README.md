# 🌟 Smart Badge · AI 智能吧唧

> 让谷子"活"过来 —— 一枚可以佩戴的二次元 AI 陪伴徽章。
> 它会呼吸、会眨眼，你摇晃它时它会跟着晃，安静时它会自己发呆。

传统吧唧是"印着角色的铁皮"，我们要做的是**"角色本人住在里面"**。

## 📐 核心规格（规划中）

| 项目 | 方案 |
|------|------|
| 屏幕 | 2.06 寸圆形 IPS LCD · 480×480 · GC9A01 |
| 主控 | ESP32-S3 N16R8（双核 240MHz · 16MB Flash · 8MB PSRAM） |
| 传感 | BMA456 加速度计（摇晃/倾斜/拿起/放下/走路感知） |
| 音频 | INMP441 麦克风 + MAX98357A 功放 + Ø20mm 扬声器 |
| 外径 | ≤ 63mm（对齐 58mm 吧唧手感） · 厚度 ≤ 12mm · ≤ 40g |
| 佩戴 | 蝴蝶扣针背扣，可直接扎在痛包上 |
| 连接 | WiFi 2.4GHz + BLE 5.0（OTA、配网、云端 AI） |

## ✨ 体验设计要点

- **陪伴感，非养成**：不喂食、不升级、没有任务 KPI，角色只是"在你身边活着"
- **柄图是灵魂**：每一帧截图都必须能当壁纸，动画幅度宁小勿崩
- **物理互动**：轻摇会晃、猛摇会晕、倾斜会滑、走路会跟着起伏
- **自主行为**：发呆、打哈欠、哼歌、自言自语 —— 它不等你操作
- **离线优先**：断网也有完整体验，联网后解锁 LLM 自由对话

## 📦 关于角色素材

本项目采用**可热插拔的独立角色资产包**（`.charpkg`）管理内容，
角色表现与硬件、固件完全解耦 —— 换角色不需要改代码。

仓库内**不包含任何角色美术、音频或视频资产**，只保留资产包的格式规范与工具链。
用于演示的角色内容需由使用者自行准备，并确保你拥有相应的权利。
